# Omid Damghani — Next.js Portfolio

A dark brutalist/minimal photography portfolio based on the approved homepage direction.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Replace photography

The demo uses remote Unsplash images. Replace the `image` URLs in `app/page.tsx` with Omid's real photographs.

For production, it is recommended to store optimized images in `/public/images` and use `next/image`.

## Main palette

- Black: `#050706`
- Dark black: `#090c0b`
- Turquoise: `#00A995`
- Emerald: `#007B69`
